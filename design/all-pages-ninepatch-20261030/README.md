# 锅里捞啥 · 四套皮肤完整设计稿

换电脑继续前，先看 [继续工作记录](继续工作记录.md)，其中记录了当前进度、迁移方式、清理结果和下一步约束。

沿用已确认的首页方案：顶部招牌与底部操作区保留原画，只有中间低细节背景随屏幕高度伸缩。子页面的页头、页脚固定，图鉴、成就、榜单和地区列表在各自内容区域滚动。

这是本地设计稿与交互预览。没有接入 Cocos 游戏工程，没有构建微信小游戏，没有连接云服务，也没有读取或修改真实玩家存档。全部数据为排版示例。

## 查看

双击 `index.html`，即可按四套皮肤、页面类别、尺寸及名称筛选。点击稿件放大，可通过界面按钮体验页面关系；方向键切换前后稿件，Esc 关闭。放大后可切换三种屏幕比例对比，也可以打开独立 PNG。

- **01 市井朱红**：原有招牌、灯笼与古铜细节；墨绿台面、米色卡片、朱红主按钮。
- **04 奶油黏土**：番茄招牌与柔软边框；奶油台面、橙色描边、绿色主按钮。
- **08 青瓷雅韵**：青瓷招牌与浅玉材质；象牙卡片、青绿色主按钮、楷体文字。
- **09 宣纸朱印**：水墨招牌与木框；宣纸底纹、克制圆角、朱印红主按钮。

## 交付范围

每套 **60 个页面、弹框与状态 + 50 个食材详情 = 110 个独立画面**，每个画面都有三种尺寸，四套合计 **1,320 张 PNG**。

| 画布 | 输出尺寸 | 排版方式 |
| --- | --- | --- |
| 标准 | 720 × 1280 | 常规密度，页头与底部固定 |
| 长屏 | 1440 × 3200 | 以 720 × 1600 布局后等比输出两倍像素；仅增加中段高度 |
| 扁屏 | 720 × 1080 | 缩短中段；调整卡片间距，长内容独立滚动 |

`png/style-01`、`style-04`、`style-08`、`style-09` 各有三个尺寸目录。一张 PNG 对应一个完整屏幕，弹框稿包含所属页面的遮罩和背景。

`components/style-*` 另提供 21 个弹框的透明背景独立组件，方便单独查看和后续交接。它们按组件自然边界输出，不计入 1,320 张全屏稿。

## 已保留的规则

- 我的小馆统计区只展示数据；地域榜单有单独入口。
- 只有江苏省提供城市与区县；其他地区选择省级后可直接保存。
- 江苏必须选完整的省、市、区县后才能保存。
- 第一关不显示道具，调试第一关禁用无限道具设置。
- 图鉴共 50 种食材；已发现与未发现有独立视觉状态。
- 成就沿用项目的 14 项清单。
- 复活用尽时主操作禁用；免费复活后展示三张食材的寄存区。
- 角色、食材、按钮和文字保持比例，随屏幕改变的只是中间背景与可用空间。

## 文件说明

- `页面与弹框清单.md`：按页面归属整理的覆盖清单。
- `overview.png`：四套风格的关键页面对比；`overview-style-*.png` 为每套常用页面总览。
- `manifest.json`：全量 PNG 的尺寸、页面 ID、布局检查结果。
- `interaction-verification.json`：设计预览中的按钮、地区、换肤及页面关系校验。
- `assets/`：本版预览需要的全部原画和食材图集，不依赖旧设计目录。
- `screen.html`、样式及脚本：只用于查看、排版和导出设计稿；不属于游戏工程。

离线直接打开不需要安装环境。如需本地 HTTP 预览，可用 Node.js 运行 `serve.cjs`，地址为 `http://127.0.0.1:8914/`。

本稿用于视觉评审；设计预览中的跳转与示例状态，不代表功能已经在游戏中实现。

我的小馆已包含“分享给好友”入口，网页环境提示到微信内分享。微信内的系统分享面板沿用平台界面，不另造系统界面。

旧版设计稿、历史运行截图和旧设计归档已删除，`design/` 下只保留本目录。`source-art/` 保留本版需要的 11 份原始背景、外框与食材图集，当前宣传封面统一放在 `assets/cover/`。
