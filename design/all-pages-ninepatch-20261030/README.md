## 交付范围

每套 **60 个页面、弹框与状态 + 50 个食材详情 = 110 个独立画面**，每个画面都有三种尺寸，四套合计 **1,320 张 PNG**。

| 画布 | 输出尺寸 | 排版方式 |
| --- | --- | --- |
| 标准 | 720 × 1280 | 常规密度，页头与底部固定 |
| 长屏 | 1440 × 3200 | 以 720 × 1600 布局后等比输出两倍像素；仅增加中段高度 |
| 扁屏 | 720 × 1080 | 缩短中段；调整卡片间距，长内容独立滚动 |

`png/style-01`、`style-04`、`style-08`、`style-09` 各有三个尺寸目录。一张 PNG 对应一个完整屏幕，弹框稿包含所属页面的遮罩和背景。

`components/style-*` 另提供 21 个弹框的透明背景独立组件，方便单独查看和后续交接。它们按组件自然边界输出，不计入 1,320 张全屏稿。

## 文件说明

- `页面与弹框清单.md`：按页面归属整理的覆盖清单。
- `overview.png`：四套风格的关键页面对比；`overview-style-*.png` 为每套常用页面总览。
- `manifest.json`：全量 PNG 的尺寸、页面 ID、布局检查结果。
- `interaction-verification.json`：设计预览中的按钮、地区、换肤及页面关系校验。
- `assets/`：本版预览需要的全部原画和食材图集，不依赖旧设计目录。
- `screen.html`、样式及脚本：只用于查看、排版和导出设计稿；不属于游戏工程。

离线直接打开不需要安装环境。如需本地 HTTP 预览，可用 Node.js 运行 `serve.cjs`，地址为 `http://127.0.0.1:8914/`。

### 重新检查与导出

在本目录运行：

```powershell
node verify.cjs
node render.cjs --check-only
node final-audit.cjs
# 修改设计后，强制重新导出全部 PNG，避免沿用旧图：
node render.cjs --force
node finish.cjs
```

脚本通过 `runtime.cjs` 查找本机 Playwright 与 Edge/Chrome，不再绑定原作者的用户目录。若未自动找到，设置 `HOTPOT_PLAYWRIGHT_PATH` 为 Playwright 模块目录、`HOTPOT_BROWSER_PATH` 为浏览器可执行文件路径；也可使用 Playwright 自带的 Chromium。仅离线浏览稿件无需安装这些工具。

`--check-only` 检查当前页面布局并写入独立的 `layout-verification.json`，不覆盖已导出的 PNG 或交付清单。默认导出会复用部分现有图片；修改稿件后请使用 `--force`，再运行 `finish.cjs` 更新组件和总览。

本稿用于视觉评审；设计预览中的跳转与示例状态，不代表功能已经在游戏中实现。
