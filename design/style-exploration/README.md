# 锅里捞啥 · 五款界面设计提案

打开 `index.html` 查看独立设计原型。顶部切换五种风格，第二排切换页面或查看整套页面。可以演示「我的 → 地域 → 保存确认」与「我的 → 页面风格 → 应用」；设计预览中的选择仅在当前打开期间有效。

## 本次范围

游戏代码只修改第一项：通关结果中的「返回游戏」调用下一关；下一关按 1 → 2 → 3 → 1 循环。其他需求仅保存于本设计目录，没有修改游戏界面、云端协议、食材配置或游戏资源。

## 50 种食材

现有 23 种图片从游戏资源原样复制；茶树菇使用独立 jzg.png，不复用原图集里未启用的金针菇。

新增 27 种：秋葵、牛蹄筋、腰花、黄喉、鸭肠、鸡爪、青口贝、扇贝、鲍鱼、鱿鱼、鱼丸、鱼籽包、鱼豆腐、豆皮、响铃卷、木耳、平菇、杏鲍菇、白萝卜、胡萝卜、南瓜、竹笋、莴笋、西兰花、花菜、芋头、红薯粉。

新增图集使用内置 ImageGen，以现有 handpainted-atlas.png 和 expanded-atlas.png 为风格参考。采用暖色手绘、立体体积、细腻食材纹理与统一光照；原有图片没有重绘。生成未得到可用透明背景，最终设计稿采用米白底版本 `assets/new-27-ivory.png`；这是评审图，正式接入前仍需透明化与逐格边界整理。

生成提示摘要：按 6 列 × 5 行排列 27 个独立火锅食材，最后三格留空；不含文字、盘子和格线；保持参考图的暖色手绘材质与左上光照。后续编辑只把彩色背景替换为统一 #fff5df 米白底，保留全部食材和位置。原始生成图保留于 assets/new-27-atlas.png。

## 验证

`verify.cjs` 从实际游戏源码中提取 nextLevel 方法，在模拟 loadLevel 上验证 [1, 2, 0]（零基索引），并检查成功弹框回调。浏览器检查 5 套 × 11 页面、50 个食材卡、切换风格、地域确认与最终关卡循环，生成截图与 verification.json。未启动 Cocos 编辑器或真机验证。

地域页面以江苏省 / 南京市为布局样例，区县可选择和搜索；省、市入口仅作信息层级示意。示例玩家资料、通关次数和成就数量均为设计占位内容。
