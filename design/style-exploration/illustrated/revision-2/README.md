# 主界面背景场景重设计 V2

用户反馈十款背景太相似，本轮从构图、空间、材质与光线重新设计全部十款。沿用已确认的控件位置、18张食材牌、7格托盘、图鉴/我的入口和底部两个按钮；菜品与品牌标题使用原图。原版设计完整保留在上级目录。

1. 青瓷竹影：开放江南月门庭院、池塘石桥、青瓷石台。
2. 锦绣朱楼：宫宴大厅、廊柱与藻井、红漆宴桌与石台。
3. 徽州水墨：全幅水墨山水、雾江、宣纸与墨砚。
4. 敦煌流金：沙漠石窟、绿洲、砂岩地面。
5. 川西竹舍：户外竹林、溪流与斜铺竹席。
6. 岭南花窗：骑楼街景、彩窗、水磨石台面。
7. 冰雪铜锅：雪夜帐篷营地、霜蓝冰台与暖光铜锅。
8. 海棠春宴：开放海棠花园、粉绢野餐台。
9. 霓虹夜市：现代街市、湿地倒影、金属与蓝紫霓虹。原「长安夜市」名称相应更新。
10. 奶油萌锅：奶油玩具厨房、圆润软陶、蜜桃与薄荷色厨柜。

背景均使用内置ImageGen生成，完整提示词和源路径位于各款generation.json；原图位置为各款assets/scene.png。提示词共同约束：竖屏720:1520，保留中心牌阵与控件位置需要的低对比空间，无文字、UI或食材牌；避免重复布幔、双灯笼、双花器、纸墙与木桌构图。

按钮、托盘的配色和材质随新场景调整，其中霓虹款改为金属冷光，青瓷款改为浅釉面，奶油款保持软陶圆润。仅设计主界面，没有新增子页面、弹框或修改游戏代码。

打开index.html查看新版；上级index.html也已更新指向新版。build.cjs生成设计HTML；render.cjs检查原图加载、牌数、槽位、入口、控件位置一致，并导出完整图、移动尺寸及对比图。验证结果见verification.json。
