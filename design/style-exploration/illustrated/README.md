# 主界面插画风格 · 第一款评审稿

本轮按用户截图重新设计游戏主界面。青瓷竹影方向已确认；新增八款，并按追加要求补充一款奶油可爱风，总计十款。不设计子页面和弹框，不修改游戏代码。

第一款「青瓷竹影」：青绿刺绣布幔、暖灯、竹影窗棂、青瓷花器、纸纹棋盘与实木桌面。按钮与七格托盘改为青绿釉面、黄铜边框。保留截图结构：标题 → 图鉴/关卡/我的 → 剩余信息 → 叠层牌阵 → 七格托盘 → 重新开始/声音。图鉴入口保留，原档案入口改为我的；无底部导航栏。

背景使用内置 ImageGen，参考游戏原背景与用户截图绘制，不含UI；标题与菜品来自项目原资源，原图复制，未重绘、变色。HTML仅用于叠加精确原图与界面文字并导出设计PNG，不属于游戏实现。牌阵与截图同样使用番茄、鹌鹑蛋与油豆腐，首关不展示道具栏。

原图：style-01/assets/scene.png。完整设计图：style-01/main-preview.png。移动尺寸：style-01/mobile-preview.png。本地预览：style-01/index.html。

最终生成提示摘要：延续原版竖屏小馆场景与宽阔安静中心，以青瓷竹影替换红布主题；上部深青绿丝绸与铜饰暖灯，两边竹影与花器，中间保持浅米纸纹，下部实木桌、铜锅、青瓷筷筒；不生成文字、按钮或食材，后期叠加原始资源。画面使用720:1520纵横比。
