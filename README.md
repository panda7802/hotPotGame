# 锅里捞啥

Cocos Creator 3.8.8 + TypeScript 竖屏叠层三消小游戏。

## 游戏说明

点击未被遮挡的食材放入七格托盘，同类自动归并，凑齐三张消除。清空棋盘和托盘即可过关；托盘中实际未消除的食材达到七张时失败。暗色食材仍被上层压住，需要先拿走遮挡它的牌。

三消触发后立即释放三个位置，消除动画未结束也能继续点牌，不会把动画中的食材计入托盘容量。单张牌飞入托盘期间仍有短暂输入锁定。

| 关卡 | 名称 | 方块数 | 层数 | 道具 |
| --- | --- | ---: | ---: | --- |
| 1 | 开锅尝鲜 | 18 | 2 | 无 |
| 2 | 热锅练手 | 30 | 2 | 撤回、炸、洗牌各一次 |
| 3 | 千层盛宴 | 888 | 37 | 撤回、炸、洗牌各一次 |

第三关每层 24 块，分六组交替采用方形和菱形布局，形成横向、纵向层叠。每张下层牌至少被紧邻上一层的两张牌覆盖，每对有遮挡关系的方块重叠面积至少为单块的 20%。同层方块不互相重叠。

- **撤回**：恢复上一次拿牌前的棋盘与托盘状态；炸或洗牌后不能撤回此前的拿牌。
- **炸**：随机选择棋盘上数量足够的一种食材，至少六张时炸掉六张，三至五张时炸掉三张。包含被遮挡的牌，不影响托盘；没有可选食材时不扣次数。
- **洗牌**：重新打乱棋盘剩余食材的种类分布，保留位置和遮挡关系。

顶部箭头可切换关卡；重新开始需要确认，并重置本关进度和道具次数。第三关通关后可从第一关再玩一遍。

## 最近改动（2026-09-29）

- 精简为三关并重新命名，保留前两关的 18、30 块；第二关起开放道具。
- 第三关扩展为 37 层、888 块，调整为横纵交错排布，避免仅擦到边角的遮挡。
- 加深被遮挡牌的牌面、边缘和食材颜色；食材明度调制为约 45%（`#737373`）。
- 炸弹图标改为深色实心球体，加入暖金描边、高光、引线和橙黄色火花。
- 三消逻辑立即结算，动画独立播放；连续消除、重开或撤回不会被旧动画回调误删新牌或误判满格。
- 补充关卡结构、可解路径与三消动画并行场景的验证脚本。
