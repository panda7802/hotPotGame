# 锅里捞啥

Cocos Creator 3.8.8 + TypeScript 竖屏叠层三消小游戏。

## 接手入口

1. [设计与开发交接](doc/锅里捞啥-设计与开发交接.md)：当前设计、代码与资源对应关系、另一台电脑启动步骤、验证清单。
2. [本轮改动记录](doc/锅里捞啥-改动记录-2026-09-28.md)：界面、食材、标题及“炸”道具的改动。
3. [运行说明](app/HotPot/README.md)：资源映射及微信构建入口。
4. [美术接入与生成记录](doc/烟火小馆美术接入.md)：原始生成提示词和资源历史。

用 Cocos Creator 打开 **`app/HotPot`**，不是仓库根目录。进入 `assets/scene/main.scene` 后预览。

历史文档仍保留“火锅叠叠消”旧名称。当前游戏正式名称为“锅里捞啥”，当前规则以设计与开发交接文档和源码为准。
