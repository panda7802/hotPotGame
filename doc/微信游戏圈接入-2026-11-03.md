# 微信游戏圈接入 · 2026-11-03

当前版本：`20261103-game-club-page-manager`。
当前实现按用户提供的新游戏圈文档，改用 `wx.createPageManager()`，不再创建透明原生游戏圈按钮。

## 游戏内行为

首页设置 → 我的小馆 → 游戏圈。四套皮肤共用现有 Cocos 菜单行。
点击后执行 `createPageManager → load({openlink}) → show()`。
已填入用户从本小游戏后台提供的“游戏内打开”值，配置在
`app/HotPot/assets/scripts/data/GameClubConfig.ts` 的 `GAME_CLUB_OPENLINK`。
微信内网页链接、微信外链接和“游戏内推荐”值均未作为游戏内打开参数。
用户提供的微信内/外网页链接均指向本项目 AppID `wx943cc2d81ec6f820`。

重复点击加载中的入口不重复请求；关闭我的小馆、组件禁用或场景销毁会释放页面实例。
异步加载结束时若原菜单已关闭，不再弹出页面；旧请求也不能清除新请求的加载锁。
返回前台不自动重开游戏圈，不修改当前棋盘、托盘、道具或存档。

网页/旧基础库显示新版微信提示，配置为空时不调用平台并显示暂未配置。
加载、显示失败时显示对应提示，并记录 `[HotPot game club] PageManager failed` 日志，
包含 `code`、`errMsg`、`errInfo`，用于真机诊断。
没有新增游戏圈数据读取、加圈奖励、图文发布、回放视频或礼包功能。

## 如何验证 AppID 的游戏圈是否开通

1. 用管理员或具备相应权限的账号登录[微信公众平台](https://mp.weixin.qq.com/)，选择“锅里捞啥”小游戏，核对 AppID 为 `wx943cc2d81ec6f820`。
2. 按用户提供的官方指南，进入“游戏能力地图 → 游戏圈”。如果后台提示开通、申请或资格要求，以页面实际状态为准，先完成对应操作。若能进入管理，查看基础设置、帖子/话题管理并取得首页 openlink，可作为后台已具备入口配置的证据。不要仅凭菜单名称出现就认定已可用。
3. 在手机微信打开用户提供的“微信内打开”链接，检查是否进入“锅里捞啥”的游戏圈且没有未开通或不可用提示。该检查验证微信侧社区可访问，不代替游戏内接口测试。
4. 微信开发者工具导入当前版本测试包，确认 AppID，基础库选择 **3.6.7 或以上**。用有预览权限的账号扫码到手机微信，点击“我的小馆 → 游戏圈”。若后台给的 openlink 有开发版/体验版/正式版生效范围，使用匹配版本。
5. 真机确实打开正确游戏的游戏圈、返回后对局正常，才算游戏内接入验收通过。若失败，开启真机调试，查看日志中的错误码和原始 `errInfo`，再对照下面排查。

[微信内打开本游戏的游戏圈](https://game.weixin.qq.com/cgi-bin/h5/lite/circlecenter/index.html?wechat_pkgid=lite_circlecenter&liteapp=liteapp%3A%2F%2Fwxalited17d79803d8c228a7eac78129f40484c%3Fpath%3Dpages%252Findex%252Findex&appid=wx943cc2d81ec6f820#wechat_redirect)

`typeof wx.createPageManager === 'function'` 只说明客户端有该 API，不能证明 AppID 游戏圈已开通。
不使用 `getGameClubData()` 探测开通状态：该接口是用户活跃信息读取能力，涉及用户授权，失败并不能直接说明社区未开通。
本次收到后台链接可确认配置来源与 AppID 一致，但尚未亲自完成真实微信页面打开验收。

## 错误码排查

以下来自[微信官方小游戏 API 类型定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)的 PageManager 说明：

| code | 排查方向 |
| --- | --- |
| -1 | openlink 是否完整正确，是否误用了微信网页链接或推荐值 |
| -2 | 基础库版本及平台支持情况，更新微信再试 |
| -3 | 当前设备或平台是否支持 |
| -4 | 业务渠道错误，查看 `errInfo`，结合游戏圈后台状态判断 |
| -5 | 其他错误，查看 `errInfo` |
| -6 | 网络连接 |
| -7 | 请求过于频繁 |
| -8 | openlink 生效的开发版、体验版或正式版是否匹配 |

任何单个失败结果都不自动标记“游戏圈未开通”。
`load` 成功只代表页面信息加载成功，仍需 `show` 成功与人工观察正确页面。
