## 技术栈与结构

- Cocos Creator 3.8.8、TypeScript；入口场景为 `app/HotPot/assets/scene/main.scene`。
- `HotPotGame.ts` 通过 Cocos Node、Graphics、Label、Sprite 动态创建界面，负责输入、游戏状态、托盘、道具、Tween 动画及 AudioSource 音频。
- `GameData.ts` 负责食材和关卡配置、固定种子的可复现牌阵、几何遮挡关系；不依赖引擎运行时。
- 资源通过 Cocos resources 动态加载，食材为透明 PNG，背景使用 JPG/PNG，音频为 MP3。
- PowerShell 构建微信小游戏；Node.js 校验脚本借用本地 Cocos 的 TypeScript 编译器检查关卡结构与解法。
- 当前是本地单机 MVP，游戏脚本没有后端接口、账号、联网排行榜或本地存档实现。

## 已有功能

- 13 种食材，10 关，单关 3～10 种、18～120 张牌、2～4 层；第 3 关起采用八行布局。
- 只能拿取未被上层覆盖的牌；进入七格托盘后同类自动归并，三个同类自动消除。
- 食材入托盘动画、消除粒子、补位动画及连续消除提示。
- 第 3 关起每关各一次撤回、移出、洗牌。移出会移除托盘末尾最多三张；洗牌重新分配剩余牌的类型。
- 顶部前后切关、剩余数量和可拿数量、重新开始二次确认、胜负弹窗与下一关。
- 首次触摸后循环播放音乐，带消除、过关、失败音效及声音开关。
- 微信小游戏构建和开发者工具启动脚本；真机/发布需对应 AppId 和平台配置。

尚未实现订单、特殊火锅牌、存档、广告、付费等功能。消除时的“+30”是即时提示，当前没有独立积分累计系统。

## 本次界面优化

- 保留暖色火锅主题，用实色顶栏和单层浅色棋盘建立清晰区域，去掉标题重影、棋盘双框及顶部装饰线。
- 按钮、进度区域、托盘和弹窗取消粗描边；食材牌保留 1px 细轮廓，便于辨认遮挡关系。
- 棋盘、托盘说明、七格槽位、道具区、操作反馈、底部按钮依次排布，避免贴边和互相挤压。
- 食材图回到牌面内部；遮挡牌使用稳定的灰褐底色和图片变暗，不再整张半透明而透出下层图案。
- 七个槽位使用 94px 间距、86px 宽度，清晰分隔；新增托盘占用数，达到五张时变为警示色。
- 道具显示“撤回 / 移出 / 洗牌”及剩余次数，增加按钮高度和点击区域。
- 减弱右下角火锅插画，避免干扰操作区。确认框及结果面板保留明确的实色背景。
