# 四套界面落地与微信小游戏交付

版本 `20261029-ui1279`。可选风格为1「青瓷竹影」、2「锦绣朱楼」、7「冰雪铜锅」、9「霓虹夜市」。默认仍为2；原先选择10号的本机偏好自动回到2。

## 已实现

- 四套背景、按钮、托盘、弹框和文字配色。青瓷月白、朱红黄铜、霜蓝磨砂、深蓝霓虹分别覆盖主界面和子页面。
- 我的小馆保留地区、图鉴、风格、地域排行榜及继续游戏，已移除身份、云存档操作和版本提示。
- 页面风格支持点选预览、确认应用和取消还原；确认后保存本机偏好。切换不重开当前关卡，不替换棋盘、托盘、寄存区、道具和撤回记录。
- 50种食材图鉴采用三列、裁剪滚动；返回食材详情后保留滚动位置；未发现的食材继续使用问号。成就页同样支持返回位置保留。
- 地区页支持全地区搜索、逐级选择和面包屑返回；末级选择后先确认，再保存。取消确认会保留关键词和选择位置。空结果提供清空搜索。
- 排行榜入口与标题统一为「地域排行榜」，按真实云端数据排序；搜索结果显示所属省市。
- 普通通关与最终通关的返回按钮、关闭按钮均按1→2→3→1推进；新成就摘要最多显示两项并补充总项数，避免文字过小。
- 失败页显示前三张暂存预览；一次免费复活用完后禁用复活按钮，重开须确认；取消重开保留当前状态。
- 调试菜单使用横排关卡选择与独立无限道具开关。「炸」按钮保留现有实心炸弹形状、暖金描边、引线与火花。
- 按钮按下时下移4设计像素；禁用按钮不触发操作；菜单关闭与返回路径保留。跨日清局时取消未提交的风格预览。

隐藏入口的后台配置和50种食材存档兼容规则没有改变，仍见[配置说明](50种食材与后台点击配置-2026-10-29.md)。云函数协议为5，首次启用仍需部署所附最新版`hotpotPlayerDev`。本轮没有部署云函数、变更云数据库或公开发布。

## 导入

1. 解压`exports/HotPot-ui1279-20261029.zip`。
2. 在微信开发者工具选择「小游戏」，导入其中的`wechatgame`文件夹。
3. AppID沿用项目原值`wx943cc2d81ec6f820`。旁边`cloudfunctions/hotpotPlayerDev`是待部署的开发云函数源码，按配置说明部署到`cloud1-d2gc9q7cobffff893`。
4. 不要将`design`、运行截图、原始场景PNG或源码目录复制进小游戏客户端目录，这些不是运行时资源。

ZIP包含客户端、云函数源码和导入/配置说明，运行截图单独保存，方便核对客户端体积。
