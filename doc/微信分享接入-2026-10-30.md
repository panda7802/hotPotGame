# 微信分享接入 · 2026-10-30

版本：`20261030-ui720-share`，源码入口为 `app/HotPot`。

在微信小游戏中打开“我的小馆”，点击“分享给好友”选择微信联系人或群聊；也可以通过右上角“…”菜单转发。四套主题均提供分享入口，六项菜单及返回游戏按钮在同一页完整显示。

分享标题为“锅里捞啥｜一起来捞一锅，看看谁能通关！”。图片采用微信默认截图，未添加额外图片资源。分享参数仅包含 `source=share` 和 `entry=button/menu`，不传玩家标识、地区或存档，也不会替换接收者的游戏进度。

点击按钮保留“我的小馆”和当前对局。微信不提供普通分享完成回调，因此不显示“分享成功”，也不根据返回时间发放奖励。网页预览或缺少接口的客户端会提示在微信小游戏内使用；同步调用异常时提示稍后重试。

- `tools/verify-design-720.cjs`：真实 Cocos 网页构建内点击四套主题入口，检查参数、对局保持、网页提示与菜单布局，同时回归原有页面交互。

接口依据：[微信官方小游戏 API 类型定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)。使用 `wx.onShareAppMessage`、`wx.showShareMenu`、`wx.shareAppMessage` 和 `wx.offShareAppMessage`。未接入朋友圈分享。
