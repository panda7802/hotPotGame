## 复现

```powershell
$env:COCOS_CREATOR_388='C:/ProgramData/cocos/editors/Creator/3.8.8'
node app/HotPot/tools/prepare-confirmed-ui.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File app/HotPot/tools/build-confirmed-ui.ps1 -Platform web-mobile
node app/HotPot/tools/verify-confirmed-ui.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File app/HotPot/tools/build-confirmed-ui.ps1 -Platform wechatgame
node app/HotPot/tools/package-confirmed-ui.cjs
```

资源准备从本轮 HTML/CSS 设计生成干净底板，保留现有资源 UUID；不将示例文字或牌堆烘焙进实际游戏。构建在 `tmp/build-confirmed-ui-20261030` 执行，不覆盖旧交付包。打包工具拒绝覆盖已存在的交付目录，制作新版本时应更新版本和目录名。构建后的云配置步骤仅生成、校验本地文件，没有上传或部署行为。
