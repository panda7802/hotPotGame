# 《锅里捞啥》拆环开锅玩法方案

## 玩家怎么玩

从「我的小馆」进入「拆环开锅」。锅边升起一块青瓷备菜板，上面是被扣在一起的食材和竹签。玩家拖动有缺口的食材环，让缺口经过银扣，扣子松脱。所有牵连解除的食材自动落入汤锅，竹签和卡扣回到备菜板边。整座机关拆空，这锅就煮好了。

**核心动作是拖着零件转动，让缺口从银扣下穿过去。** 每个环有自己的转轴。银扣的花纹端属于被挂住的零件，光滑端套在另一个零件的环身上。自己的扣还被挂住时，零件固定。能转的环仍可能托着别人的扣，缺口依次扫过这些位置就能放走它们。同一个闭合藕片可以挂在两个开口环上，两个连接都解除才下锅。抽杆沿自身直段滑，末端退出环口后，原先被挡住的环才有转动空间。

### 第一锅

四件零件组成一道题。左侧一根竹签挡住中间鱿鱼卷的缺口，鱿鱼卷托着外侧香菇圈的一枚银扣。香菇圈和鱿鱼卷又各托着同一片闭口藕片的一枚扣。

1. 向左抽竹签，鱿鱼卷获得转动空间。竹签滑进筷架。
2. 转鱿鱼卷，先让开口经过香菇圈的银扣，再经过藕片靠鱿鱼卷的一枚扣。鱿鱼卷脱落，香菇圈能转了。
3. 转香菇圈，解开藕片的另一枚扣。香菇圈和藕片连续落进汤底，冒出水花。

按住可转的食材环时，高亮它的缺口和当前能解的银扣。按到被扣住的零件时，轻晃一下并高亮挂住它的扣。每次解扣都有一声短促的「咔哒」，落锅再给一声「咕嘟」。首版采用随时撤回和重开，玩家可以花时间看连接关系。

### 界面和美术

- 主画面上方保留《锅里捞啥》青瓷标题，中央是竖向备菜板，底部露出一口正在煮的锅。棋盘安排稀密有别的食材枝组，方便手指抓住单个零件。
- 开口件用鱿鱼卷、香菇圈等有明显切口的轮廓。闭口件用藕片或成圈洋葱，杆件用竹签和长筷。金属扣和食材使用不同材质，空隙用桌面颜色，扣的固定端与套入端能从形状分辨。
- 去掉同心盘设定，零件彼此连接，悬在各自的位置。效果图主镜头可放一片被左右两扣挂住的藕片，其中一个扣刚从鱿鱼卷的缺口滑出，另一个扣清晰可见。

## 落进现有游戏的两种方式

| 方式 | 一局的目标 | 适用与代价 |
| --- | --- | --- |
| **独立解环短关，首版推荐** | 拆空所有机关，食材直接落锅 | 解扣反馈清晰。可复用现有青瓷界面、食材配置、音效和部分结算表现。优先验证旋转手感与拆解节奏。 |
| 解环后进七格待煮盘，后续候选 | 拆环时选择先放哪种食材，同类凑三份下锅 | 适合做进阶模式。需要给玩家两条以上可拆的分支，并校验拆除顺序、自动掉落顺序与七格容量。否则会出现唯一合法的解扣顺序却必然满盘。 |

## 工程可行性和原型范围

现有 Cocos Creator 3.8.8 + TypeScript 可以承载这套 2D 玩法。每件零件记录中心、旋转角或滑动位置，银扣记录固定端、套入端和脱扣角度。拖动沿中心求角度差，检查这帧扫过的角度区间，快速扫过缺口也能正常脱扣。同一帧多个扣被扫过时按经过顺序处理。抽杆走指定轨道，取到末端才解除挡位。逻辑先更新连接和掉落状态，动效跟随状态播放。触摸重叠时优先按环边命中，选中后锁定该件直到松手。

关卡先定通关动作，再把零件倒序扣回去。固定关用同一套判定重放解法，确认滑杆能退出、可转角度内能碰到对应卡扣、最后所有零件自动结算。加入限位后须检查角度与顺序，单看连接关系推不出可解性。首版以三张固定盘面验证：

| 关卡 | 目标 |
| --- | --- |
| 3 件 | 一转解一扣，感受食材落锅。 |
| 4 件 | 「第一锅」示例，学会先抽杆，再依次释放双扣藕片。 |
| 8–10 件 | 两组机关，其中一组释放后给另一组让出抽杆空间，观察玩家能否自行找第一步。 |

首轮验收重点是能否在十秒内自己解开第一枚扣、能否说明闭口藕片还卡在哪，以及掉落动画会不会妨碍下一次触摸。样式先做一套，真机观察环边命中、短拖精度和窄屏银扣辨识度。原型独立记录本地进度。正式接入图鉴、餐谱奖励或副本道具发放时再明确结算规则。

## 参考截图第 3 关的推演

按截图分成六组，共 45 个可辨识零件。花纹端和光滑端的作用是依据图中闭口零件和卡扣朝向反推的。下表在该连接模型中重放后可清空 45 件，游戏实机的限位和自动掉落仍待现场验证。
