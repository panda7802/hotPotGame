# 通关图压缩与超过 4M 分包验证（2026-11-04）

## 用户要求

保留四主题 × 三关通关弹框需求，降低运行图片尺寸与体积。整体客户端保持超过 4M，验证实际 Creator 构建及微信开发者工具分包流程。

## 压缩方式

- 四张通关图由 1210×1300 PNG 改为 **720×774 JPEG，质量 84，4:4:4 色度采样**。720 像素覆盖约 360 CSS 像素弹框的 2 倍屏显示。
- 四张图合计从 **9,727,586 字节** 降至 **688,657 字节**，减少约 **92.9%**。
- 原始设计图继续保留在 `design/victory-dialog-20261104/background-*.png`，不进入客户端。
- 运行文件改为 `assets/victory/style-01/04/08/09/win.jpg`，沿用原资源 UUID 和 `win/texture` 加载路径；旧 PNG 及其导入元数据移除，隔离构建脚本同时清除旧拷贝。
- 文字、统计与真实按钮保持动态，四个独立主题分包继续按需加载。没有添加占位资源来凑大小。

- 53 个 TypeScript 模块检查通过。

## 使用

版本：`20261104-victory-mobile`。本机 `app/HotPot/build/wechatgame-cloud-dev` 已同步压缩版，旧原图产物已排除。

独立交付为 `exports/HotPot-victory-mobile-20261104/wechatgame`，导入该目录继续按现有流程预览、上传。扩展须使用 1.0.5；更新后若编辑器尚未重开，彻底退出再打开一次，构建日志应出现“分包校验 v2”。

图集生成工具为 `tools/prepare-victory-dialogs.cjs`；重新构建仍使用 `tools/wechat-cloud-dev.build.json` 或 `tools/build-hidden-ingredients.ps1 -Platform wechatgame`。对局协议保持 7，无须为图片压缩重复部署同版云函数。
