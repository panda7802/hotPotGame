# 《锅里捞啥》烹饪与餐谱系统方案

玩家在三消里点亮食材，回到小馆把食材做成菜。餐谱记录出品和最高星级，玩家可以发给好友约做同一道菜。

## 从三消首页到第一次出锅

| 页面 | 玩家看到什么 | 怎么走 |
| --- | --- | --- |
| 三消首页 | 打开游戏直接进入牌阵。第一次从「第 1 关 · 开锅尝鲜」开始，底部是七格托盘。标题两侧放「图鉴」和小号「烹饪」入口，未解锁时烹饪带 `0/10` 进度。 | 直接捞牌。点尚未解锁的烹饪入口，可以到图鉴查看进度。已解锁后点同一入口直达餐谱。 |
| 食材图鉴 | 继续按普通、珍藏浏览。标题下方同时显示图鉴总进度和烹饪门槛，例如「已发现 9/60」「烹饪解锁 9/10」。 | 点「返回」回到刚才的牌阵，继续收集。 |
| 第 10 种食材 | 本次新收录豆腐后显示一次「烹饪已解锁」，弹层在牌和托盘动画结束后出现。 | 「继续捞锅」关闭弹层。「去餐谱」打开餐谱，三消对局存下来。 |
| 我的餐谱 | 点亮豆腐后，已有番茄的玩家可以做番茄豆腐汤。列表同时展示其他菜的解锁状态和「小馆进阶」进度。 | 点菜卡进入详情，点页面底部「返回」回到原来的三消对局。 |
| 餐谱详情 | 查看难度、满分及配料。食材已齐的番茄豆腐汤显示「开始烹饪」。缺料时查看「已有食材」「缺失食材」。 | 「开始烹饪」进入接料。点缺失项可查看对应图鉴，再返回这道菜，或回三消收集。 |
| 接料与出锅 | 窄盘接料，显示当前份数，可选点按或倾斜。 | 点「出锅」查看星级、出品分及配料差异。 |
| 结算 | 示例是番茄 3/3、豆腐 2/3，83 出品分、3 星。该道菜开始 10 分钟重做倒计时。 | 可以发给好友、看广告立即重做，或「返回餐谱」挑另一道。从餐谱返回后继续原来的三消。 |

图鉴和烹饪使用同一份发现记录。玩家从餐谱、接料或结算返回三消时，棋盘、托盘和道具次数恢复到离开时的状态。奶油风首页把暖白和蜂蜜金留给棋盘和卡片，叶绿用于可执行的主要操作。收集进度放在棋盘外。

## 1. 烹饪怎么玩

**达到 10 种不同的食材即解锁。** 普通和珍藏均计入，按已收录的图鉴 ID 去重。首次在三消中达到门槛时，弹层提供「去餐谱」和「继续捞锅」。老玩家读档或完成云同步后按同一规则解锁，直接使用首页烹饪入口。

1. **选菜。** 进入「我的餐谱」，首屏显示三道首发菜，优先推荐可做的一道。「小馆双拼」用玩家已发现的两种食材教学，每种 2 份。双拼可反复游玩，首批菜暂时都未解锁时作为首屏推荐。
2. **用窄盘接料。** 食材从四列落下，盘子在四个落位之间移动。默认「点按」，点底部左、右键分别移动一列。切到「倾斜」时，以竖屏握姿校准中位，读取绕手机 Y 轴的相对角度。低于 −45° 选第一列，−45° 至低于 −10° 选第二列，高于 10° 至 45° 选第三列，高于 45° 选第四列。−10° 至 10° 保持当前列。记住玩家上次的选择，传感器不可用时回到点按，局内切换先暂停。
3. **接取判定。** 盘口宽约为单列的四分之三，接取范围与盘口一致。食材到达接取高度时，只有盘子已经到位且食材落在盘口内才计 1 份，滑过相邻列时不会顺带接料。可以主动把盘子移到空列，放过已够量的食材。普通局至少留一列可避让，并错开连续目标的到达时间，两种控制用同样的出料和评分。
4. **点「出锅」。** 上方计数显示「已接 / 需要」，接满打勾，超量或混入杂料时显示本盘多出的份数。接到至少一份即可提交，最后一波落完后留在盘点画面。空盘提供「再试一次」。切后台冻结出料，玩家回来后自行继续。

普通局按约 25 秒试做。出料先安排目标食材，每种额外留 1～2 次补接机会，再从玩家已收录的其他食材中抽取少量干扰。随机的是顺序和落列，每次生成都检查份数、连续目标之间的可达时间和可避让列。难度由落速、配方份数、批次和干扰频率控制。教学局放慢最早几份食材。

**多食材餐谱分批下料。** 2～3 种食材一批完成，4 种按 2＋2，5 种按 3＋2，6 种按 3＋3。顶部显示批次和本批最多三张食材计数卡，卡片与落料使用同一食材图标。接满的卡片打勾，四列落道留给下落食材。已接结果保留到结算。上一批结束后暂停出料，点「下一批」再继续。

以六种食材的「海味什锦煲」为例，第一批接帝王蟹 2、鲜虾 4、鱼片 4，第二批接扇贝 3、豆腐 3、青菜 2。第一批未结束时「下一批」按钮置灰。本批份数全部刚好或本批出料结束后可点「下一批」，未接齐的份数照实记入结果。最后一批用「出锅」。两批共 18 份，整道菜按全部食材统一计分，结算可以展开各批明细。

## 2. 准确率、星级和出品分

**满星需要每种食材的份数都准确。** 把少料和多料分别加总，取两者的较大值作为误差份数。一次拿错相当于换错一份，同时产生的少料和多料合计只扣一份。份数比例相同但整盘分量不对，仍扣分。速度和接取顺序不参与普通局评分。

> 准确率 = max(0, 1 − max(少料总份数, 多料总份数) ÷ 目标总份数)。杂料的目标份数为 0。

| 准确率 | 星级 |
| --- | --- |
| 100% | 5 星 |
| 85% 至低于 100% | 4 星 |
| 70% 至低于 85% | 3 星 |
| 55% 至低于 70% | 2 星 |
| 大于 0% 至低于 55% | 1 星 |
| 0% | 0 星 |

**每道菜有自己的出品满分。** 难度 1、2、3 的基础满分分别为 100、140、180。配方每多需要一种不同的珍藏食材，满分再加 15。普通食材加 0。同一种珍藏需要多份时只加一次，额外接到珍藏仍按错料处理。

> 出品分 = 四舍五入（准确率 × 餐谱满分）。星级使用未取整的准确率。

同为 87.5% 准确率，满分 100 的基础菜得 **88 出品分**，假设难度 3 的佛跳墙需要 4 种珍藏食材，满分 240，得 **210 出品分**。两盘均为 4 星。详情页展示菜的难度和满分，结算页展示本盘星级、出品分和份数差异。

以满分暂定 100 的「酸汤肥牛」为例，目标为肥牛 5 份、金针菇 3 份。

| 实际出品 | 反馈 | 出品分 / 星级 |
| --- | --- | --- |
| 5 份肥牛 + 3 份金针菇 | 份量刚好 | 100 / 5 星 |
| 6 份肥牛 + 2 份金针菇 | 肥牛多 1 份，金针菇少 1 份 | 88 / 4 星 |
| 5 份肥牛 + 1 份金针菇 | 金针菇少 2 份 | 75 / 3 星 |
| 5 份肥牛 + 3 份金针菇 + 1 份玉米 | 混入 1 份玉米 | 88 / 4 星 |
| 10 份肥牛 + 6 份金针菇 | 两种食材都超量 | 0 / 0 星 |

第一次达到 **3 星**点亮餐谱成品，**5 星**获得金边菜牌。每道菜保留历史最佳和对应的配料结果，重做失误时保留最佳记录。

## 3. 三消、图鉴与餐谱怎么对接

| 现有系统 | 接入方式 |
| --- | --- |
| 首页与三消 | 首页并列展示「图鉴」「烹饪」。烹饪作为独立页面和对局，退出后回到原入口，三消牌阵、托盘和关卡进度继续走现有存档。 |
| 食材图鉴 | 复用 `progress.discovered`、食材 ID、图标及普通／珍藏分类。新食材点亮后重新判断餐谱解锁条件。详情页按图鉴是否收录将配方分成「已有食材」和「缺失食材」。已收录食材可反复使用。 |
| 我的成就 / 小馆 | 在个人资料下方并排显示「三消通关」和「烹饪通关」累计次数，食材发现和已获成就显示在下方。新增「第一道菜」「三道五星菜」「珍藏上桌」成就。 |
| 玩家存档 | 旧档初始化空的烹饪进度，解锁状态按图鉴和小馆进度计算。记录餐谱版本、最佳分数、首次达标和各道菜的冷却结束时间。跨设备对同一餐谱版本合并最佳分数、取最早达标时间。结算按对局 ID 去重，重做放行按餐谱 ID 和冷却状态核对。 |
| 排行榜与现有奖励 | 排行榜包含「通关」和「餐谱五星」。烹饪首发奖励用菜牌和成就，正式餐谱的五星记录用于餐谱榜，地域通关数据沿用现有规则。 |

### 餐谱结构与首发内容

每道菜配置稳定的餐谱 ID、名称、食材 ID 与目标份数、所需小馆进度、分类、难度、封面、出料节奏和规则版本。配方变更时创建新版本，历史出品按原版本保留。

- **未解锁**在列表显示菜名、成品图和锁定状态。详情可查看完整食材，按已收录和未收录分组。需要进阶时显示进阶条件。
- **可烹饪**表示达到所需小馆进度，配方食材都已在图鉴收录。
- **已出品**表示历史达到 3 星，菜卡显示最高星和出品记录。

现有图鉴有牛肉、茶树菇，没有独立的肥牛、金针菇。要按原配方做「酸汤肥牛」，需先把肥牛和金针菇纳入图鉴及三消发现池，再上线这道菜。首发份数是游戏配方，供试玩调节。

### 解锁顺序

| 小馆进度 | 何时展示 | 何时能做 |
| --- | --- | --- |
| 首次进厨房 | 收录满 10 种食材后，餐谱显示「番茄豆腐汤」（番茄 3、豆腐 3）、「鲜虾玉米煲」（鲜虾 4、玉米 3）和「牛肉菌菇煲」（牛肉 5、茶树菇 3） | 各自凑齐图鉴食材即可开做。 |
| 小馆进阶 | 任意两道不同的正式餐谱达到 3 星。解锁前只展示小馆进阶卡和 `0/2`、`1/2` 进度 | 进阶菜加入同一份餐谱，食材已齐即可开做。 |

按不同餐谱 ID 累计达标，重做同一道只算一道。「小馆双拼」是练习。首次达标时结算提示进阶进度，返回餐谱后显示刚加入的菜。小馆进阶资格长期有效。珍藏菜可以作为进阶后的长期收集目标，例如「松茸鲜汤」（松茸 3、鱼片 3）。

### 后续怎么上新

- **上新就追加到同一份餐谱。** 可以先按约 4 周加 2～3 道试做，优先复用现有食材。新菜按配置加入基础或进阶餐谱，符合图鉴和进阶条件即可开做。已上线的餐谱永久保留，出品和星级随原记录继续展示。
- **数量多后再做分类。** 首版一份列表。菜变多以后可按汤羹、煲锅、珍藏等分类，或者提供「可烹饪」「已出品」筛选。分类只改变查找方式，所有菜仍在同一份餐谱中。

### 排行榜

- **通关**默认打开，沿用现有地域榜和通关统计。两个榜签放在「排行榜」标题下方。
- **餐谱五星**和通关共用「全国／省内／市内」筛选，以及玩家已选的地区。选「省内」显示本省达成全五星的玩家，选「市内」显示本市达成的玩家。缺少相应地区信息时，可沿用通关榜的地区选择入口。榜单标题显示当前范围，例如「江苏省 · 13 道餐谱全五星入榜」。
- **入榜条件**是当前已发布的每道正式餐谱均拿到 5 星。尚未达成时仍可查看所选地域的榜单和自己的进度，例如「8/13，还差 5 道」，点「去餐谱」继续。图鉴未集齐或仍处于进阶锁定的正式餐谱也计入总数，小馆双拼练习不计。所选地域还没有玩家达成时，显示空榜和个人进度。
- **所选地域内按最早达成当前全五星的时间排序。** 服务端记录每道餐谱首次拿到五星的时间，最后一道达标时写入达成时间。同菜重复五星只算一道。以后新增餐谱时保留旧星级和达成记录，当前榜总数随已发布餐谱增加。比如原来 13/13 的玩家遇到新菜显示 13/14，拿到新增菜的五星后进入当前榜。

## 4. 餐谱展示和社交

- **我的小馆**的「三消通关」沿用原来的个人累计通关，任一关成功完成一次加 1。「烹饪通关」每完成一局正式餐谱并达到 3 星加 1，同一道菜再次达标也计一次，教学练习不计。两个数按对局 ID 去重。地域榜按各自的入榜规则展示成绩。
- **我的餐谱**用一份列表展示成品图、可烹饪或未解锁状态，以及已出品菜的最高星。小馆进阶卡留在列表内。
- **餐谱详情**显示难度、出品满分和个人最佳。「已有食材」和「缺失食材」分别列出食材、配方所需份数和图标，缺失项可点到对应图鉴。已有表示已收录，份数是本局目标。佛跳墙等长配方的两组标题显示种类数量，可展开查看。缺料时主按钮是「去图鉴」，食材和进阶条件都满足后显示「开始烹饪」或当前冷却。
- **好友点单**作为首发社交。结算页点「请好友也做一盘」，使用现有微信分享入口，卡片打开对应餐谱详情，好友按自己的图鉴和冷却记录开做。发起者的星级可展示。
- **同一盘挑战**作为后续玩法。好友用相同的餐谱版本、随机种子、节奏和落列比准确度，同分并列。挑战的出料使用双方均已收录的配方食材。云端保存挑战 ID、规则版本和双方结算，排行榜或勋章使用服务端核算的成绩。游戏圈可以推荐一道菜，引导玩家分享出品。

## 5. 重做冷却和广告

| 状态 | 页面行为 | 广告 |
| --- | --- | --- |
| 完成一局 | 先保存星级、出品分和最佳成绩。该道菜从结算起进入 10 分钟冷却，其他菜照常可做。 | 结算与餐谱详情可显示「看广告立即重做」。 |
| 冷却中 | 显示「重做剩余 09:59」等倒计时。玩家可分享或返回餐谱。 | 完整观看后，本次冷却解除，可立即开始同一道菜。 |
| 冷却结束 | 按钮恢复为「再做一次」。 | 收起广告按钮。 |

冷却按账号和餐谱 ID 计算，切页、重启或换设备继续倒计时。新一局结算时重新计时，广告解锁仅对应当前这一次冷却，按对局 ID 去重。广告无填充、失败或提前关闭时回到原页继续计时。广告期间如果倒计时已结束，正常开做。退出未结算的对局不触发冷却。「小馆双拼」为教学练习，可反复进入。微信转发和激励视频可参考官方接口示例。[微信小游戏接口示例](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/test/game.test.ts)

## 6. 上线顺序与验收

1. **先做核心玩法。** 验证图鉴解锁、详情分组、点按和倾斜控制、星级与出品分。真机检查初次校准、移动跨列时的接取判定和切换控制方式。实现跨设备烹饪存档时，需要重新部署配套云函数 `hotpotPlayerDev`，本地上传目录为 `app/HotPot/cloudfunctions/hotpotPlayerDev`，先在开发环境配套验证。烹饪页面复用四套主题和食材图标，餐谱封面按需加载。
2. **接入重做、好友点单和餐谱五星榜。** 验证跨页面、跨设备和好友入口的冷却一致，验证视频完成、提前关闭、无填充和重复回调。验证单道重复五星、全五星首次入榜，以及上新后保留旧星级并增加目标总数。
3. **后续加入「同一盘挑战」和大菜。** 验证多食材详情、分批出料和整体评分。
